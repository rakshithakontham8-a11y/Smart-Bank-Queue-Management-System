# 🏦 Smart Bank Queue Management System

A Smart Bank Queue Management System designed to reduce customer waiting time and efficiently manage bank queues using digital tokens.

## 📌 Project Overview

The Smart Bank Queue Management System allows bank customers to register for services and receive a digital queue token.

The system helps bank staff manage customers, monitor the live queue, call the next customer, and track completed services through an Admin Dashboard.

## ✨ Features

- 🎫 Customer Registration
- 🔢 Automatic Token Generation
- 📱 QR Code Token
- 📊 Live Queue Management
- 📢 Now Serving System
- ✅ Service Completion Tracking
- 📈 Admin Dashboard
- ⭐ Most Requested Service
- 📊 Queue Statistics
- 👥 Customer Records
- ⏱️ Estimated Waiting Time
- 💾 SQLite Database

## 🛠️ Technologies Used

- Python
- Streamlit
- SQLAlchemy
- SQLite
- QR Code
- HTML/CSS
